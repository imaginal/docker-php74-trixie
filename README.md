# PHP 7.4 FPM for Debian Trixie

This repository provides an unofficial port of the Docker Official Image `php:7.4-fpm`, updated to build and run on Debian Trixie.

The image is built from the official PHP source branch [`PHP-7.4-CVE-2026-109618-109619`](https://github.com/php/php-src/tree/PHP-7.4-CVE-2026-109618-109619), which includes backported security fixes for **CVE-2026-109618** and **CVE-2026-109619**, as well as compatibility fixes for `ext/intl` and `ext/openssl` required for Debian Trixie and OpenSSL 3.

## Build   

Use the `make_dist.sh` script to automate the entire build process. It clones `php-src`, applies necessary patches, and generates the distribution package.

Note: The script runs inside a Docker container, so no additional dependencies or tools are required on your host system except for Docker.

```
  # 1. clone php-src, apply patch and makedist

  cd php-dist

  ./make_dist.sh -d

  # 2. copy php-7.4.34.tar.xz

  cp php-dist/php-src/php-7.4.34.tar.xz 7.4/trixie/fpm/

  # 3. build docker image

  cd 7.4/trixie/fpm

  docker build -t php:7.4-fpm-trixie .

  # 4. chek result

  docker run --rm php:7.4-fpm-trixie php -v
```
